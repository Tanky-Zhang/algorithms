附：面试做题四步识别法
1. 先看数据结构载体
- 数组
- 链表
- 树
- 图
- 字符串
2. 再看是否有明显特征
- 有序 -> 二分 / 双指针
- 连续子数组 / 子串 -> 滑动窗口 / 前缀和
- 最值 / 第 K / 动态维护 -> 堆 / 单调结构
- 所有方案 / 枚举路径 -> 回溯 / DFS
- 最短步数 / 最少操作 -> BFS / 最短路
- 状态转移 / 最优解 -> DP
3. 判断约束规模
- n <= 20：回溯 / 状压
- n <= 10^3：可接受 O(n^2)
- n <= 10^5：通常要 O(n log n) 或 O(n)
4. 最后套模型表达
   标准表达：
- 这题我先看数据范围和题目目标。
- 题目要求的是连续区间，而且要在线性时间内处理，所以我优先想到滑动窗口 / 前缀和。
- 这里存在明显的单调性，所以可以用二分答案。
- 这题本质是在每个位置做决策，因此可以抽象成动态规划。
