# 438. 找到字符串中所有字母异位词 · 中等

来源：[力扣官方题目](https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/)，2026-11-26 核对。

给定 s 和 p，返回 s 中所有与 p 字母种类、数量相同的连续子串的起始下标。顺序不限，匹配可以重叠。

约束：1 ≤ s.length,p.length ≤ 30000，均只含小写英文字母。

"cbaebabacd","abc" → [0,6]。
"abab","ab" → [0,1,2]。

模板：src/main/java/com/tanky/hot100/slidingwindow/FindAllAnagramsInAString.java。
测试：src/test/java/com/tanky/hot100/slidingwindow/FindAllAnagramsInAStringTest.java。
运行：mvn -Dtest=FindAllAnagramsInAStringTest test。

11 组测试覆盖官方示例、p 比 s 长、重复字符计数、重叠匹配、无解、单字符、最后一个窗口、窗口经过无关字符及最大长度。
