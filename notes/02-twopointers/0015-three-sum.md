# 15. 三数之和 · 中等

来源：[力扣官方题目](https://leetcode.cn/problems/3sum/description/)，2026-11-25 核对。

返回整数数组中所有和为 0 的不重复值三元组。三个元素必须来自不同下标；允许数值重复，只要输入中存在足够的位置。三元组内部和结果列表顺序不限。

约束：3 ≤ nums.length ≤ 3000；-10^5 ≤ nums[i] ≤ 10^5。

[-1,0,1,2,-1,-4] → [[-1,-1,2],[-1,0,1]]。
[0,1,1] → []；[0,0,0] → [[0,0,0]]。

模板：src/main/java/com/tanky/hot100/twopointers/ThreeSum.java。
测试：src/test/java/com/tanky/hot100/twopointers/ThreeSumTest.java。
运行：mvn -Dtest=ThreeSumTest test。

10 组测试覆盖重复固定值、重复左右值、全零、无解、数值边界与多个结果。不以 Set 吞掉重复结果，检查返回三元组能由输入不同位置构成。
