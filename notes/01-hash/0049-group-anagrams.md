# 49. 字母异位词分组 · 中等

来源：[力扣官方题目](https://leetcode.cn/problems/group-anagrams/description/)，2026-11-25 核对。以下为题意转述。

把字符串数组中可以通过重新排列字母互相得到的字符串归入同一组。组间、组内顺序不限；每个输入字符串都要保留，包括重复字符串和空字符串。

约束：1 ≤ strs.length ≤ 10^4；0 ≤ strs[i].length ≤ 100；仅包含小写英文字母。

示例：["eat","tea","tan","ate","nat","bat"] → [["eat","tea","ate"],["tan","nat"],["bat"]]。
[""] → [[""]]；["a"] → [["a"]]。

模板：src/main/java/com/tanky/hot100/hash/GroupAnagrams.java。
测试：src/test/java/com/tanky/hot100/hash/GroupAnagramsTest.java。
运行：mvn -Dtest=GroupAnagramsTest test。

测试覆盖官方示例、重复空串、重复单词、相同字母但数量不同、全部分开以及长度 100；不要求固定返回顺序。

## 本人思路

本人提出：将每个字符串的字母排序，用排序后的字符串作为 Map 的 key，value 保存对应原始字符串的列表，最后返回所有分组。

边界：空串会生成空 key，重复字符串仍逐个加入列表，字母种类相同但数量不同的字符串具有不同排序键。返回组间顺序不固定符合题意。排序只修改 toCharArray 生成的副本，分组中保存原始 str。

复杂度：n 为字符串数、k 为最大长度，以排序法通用上界计，期望时间 O(n·k log k)（k≤1 时仍有逐项处理成本，可统一写 O(n·(1+k log(k+1)))）。HashMap 操作为平均成本。设 g 为组数，键空间 O(gk)，分组和返回列表保存 O(n) 个引用，临时字符数组 O(k)，额外空间 O(gk+n+k)，通常粗略记 O(nk+n)；不会复制所有原始字符串内容。

代码质量：命名清楚、流程正确。可选用 computeIfAbsent 简化分支并减少重复查找，但不要求改写。暂不提前提供另一种核心算法。

## 通用思想与面试表达

通用思想：为等价对象生成规范表示，再用 Map 聚合。排序键相同，当且仅当两个字符串的字母种类和各字母数量相同。

面试表达：我将每个字符串排序后作为分组键，用 Map 保存该键对应的原始字符串列表。字母异位词排序结果相同，因此会进入同一组。遍历完成后返回 Map 中所有列表。排序用字符数组副本，不改变原始字符串。
