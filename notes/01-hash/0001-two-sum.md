# 1. 两数之和 · 简单

来源：[力扣官方题目](https://leetcode.cn/problems/two-sum/description/)。以下为题意转述。

给你整数数组 nums 和目标整数 target，返回两个不同位置的下标，使对应元素之和为 target。保证恰好存在一组有效答案；返回顺序不限，同一位置不能使用两次。

约束：2 ≤ nums.length ≤ 10^4；-10^9 ≤ nums[i], target ≤ 10^9。重复数值允许出现。

| nums | target | 可接受输出 |
| --- | --- | --- |
| [2,7,11,15] | 9 | [0,1] 或 [1,0] |
| [3,2,4] | 6 | [1,2] 或 [2,1] |
| [3,3] | 6 | [0,1] 或 [1,0] |

模板：src/main/java/com/tanky/hot100/hash/TwoSum.java。
测试：src/test/java/com/tanky/hot100/hash/TwoSumTest.java，另覆盖负数、零、避免重复使用位置、大数边界。

先说出你的直观方法、如何保证下标不同，以及预计复杂度，再写代码。官方进阶目标：时间复杂度低于 O(n²)，可在基础实现之后讨论。

## 本人思路

使用 HashMap 保存已遍历元素的值及其下标。遍历当前位置时先查询所需的另一个数，找到则返回两个下标，否则记录当前值与下标。

## 测试失败与原因

2026-11-24：执行 mvn -Dtest=TwoSumTest test，7 组全部通过，失败 0、错误 0、跳过 0。本次审查未发现题目约束内的正确性问题，未修改算法代码。

边界审查：先查再存使 Map 只包含当前位置之前的元素，因此不会使用同一下标两次；重复值、零和负数均可处理。相同值覆盖旧下标不影响寻找有效配对。题目范围内 target - nums[i] 位于 [-2×10^9, 2×10^9]，不会溢出 int。题目保证有解，末尾 [-1,-1] 分支不会在合法输入中到达。

## 通用思想与面试表达

通用思想：把“为当前元素寻找配对”的重复扫描转换为哈希查询；明确辅助结构在每轮开始时保存的内容。

关键不变量：处理下标 i 时，Map 中的每个下标都小于 i。找到配对就能保证下标不同；尚未找到则加入当前元素，保持下一轮不变量。

复杂度：HashMap 查询与插入平均 O(1)，整体期望时间 O(n)，额外空间 O(n)；不是无条件的最坏 O(n) 保证。

代码质量：命名和流程清晰；可自行移除过时 TODO、修正注释“同时同时”，将差值提取为变量避免重复计算。当前 containsKey 再 get 查询两次，可讨论合并为一次 get（本实现不会存 null）；提前 return 后的 else 可省略。以上均非正确性问题。

面试表达：我用 Map 保存已经遍历的数和下标。对每个数先查找目标值减去当前值，找到就返回两个下标，否则记录当前元素。因为查询发生在插入之前，匹配到的位置一定在当前下标之前，不会重复使用同一元素。期望时间 O(n)，额外空间 O(n)。
