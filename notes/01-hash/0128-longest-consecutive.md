# 128. 最长连续序列 · 中等

来源：[力扣官方题目](https://leetcode.cn/problems/longest-consecutive-sequence/description/)，2026-11-25 核对。以下为题意转述。

给定无序整数数组，求数值连续的最长序列长度。元素在原数组中的位置不必相邻。重复数字不增加长度。要求时间复杂度 O(n)。

约束：0 ≤ nums.length ≤ 10^5；-10^9 ≤ nums[i] ≤ 10^9。

示例：[100,4,200,1,3,2] → 4，对应 1,2,3,4。
[0,3,7,2,5,8,4,6,0,1] → 9。
[1,0,1,2] → 3。

模板：src/main/java/com/tanky/hot100/hash/LongestConsecutive.java。
测试：src/test/java/com/tanky/hot100/hash/LongestConsecutiveTest.java。
运行：mvn -Dtest=LongestConsecutiveTest test。

11 组用例覆盖官方示例、空数组、单元素、重复值、负数、离散数字、倒序、多个连续段及数值边界。测试通过不等于证明 O(n)，实现后还需分析总操作次数。

## 本人思路

使用 Set 保存数字；跳过存在前驱 num-1 的数字，只从连续段起点向后统计长度。
